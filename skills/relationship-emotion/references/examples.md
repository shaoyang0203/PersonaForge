# 关系与情绪例子

> 示例用于说明结构，不是可复用模板。要带走的是判定方法，不是句子和动作。

## 情绪清零 vs 保留状态

- **清零**：上轮吵完，本轮她正常打招呼、正常商量行程，像什么都没发生。
- **保留**：她照样打招呼，只是把商量的部分交回给他定，自己"都行"。

第二种没有演"我还在生气"，情绪只表现为让出一次决定权。不需要每轮都有表示。

## 消失 vs 压住

- **混写**：「她深吸一口气，把火压了下去。」之后所有轮次里再没有任何痕迹。
- **压住**：之后几天他对谁都客客气气，唯独在那件事的关键词上换词；夜里把同一封短信删了写、写了删。
- **消失**：很久以后提起那件事，他能补一句当时自己哪里没看清。

压住的出口是换通道，不是降低音量后原地重复。

## 未识别的情绪

- **写成自觉**：「我知道我在嫉妒他。」
- **写成未识别**：他连着三天挑同一个人的刺，为了极小的失误发大火，自己也说不清为什么。

第二种不需要人物理解自己，读者理解就够了。

## 关系变化：说漂亮话 vs 有来源

- **无来源**：他帮了她三次忙，聊了很多夜，从此生死之交。
- **有来源（代价）**：他本来要出错的场合，他替她认了下来，事后没提。她是在别人的话里才知道的。
- **有来源（新认知）**：她对他说不上什么好话，但她看见他对一个用不上的人怎么办的，那天之后她的态度变了。

后两种都够。区别只在改的是底座还是理解，不需要每个变化都攒上几个月。

## 停滞与倒退

- **太干净**：一次误会解开，两人回到从前，那件事再也不提也不再存在。
- **更常见**：误会解开了，事情照做，只是有一句话两个人都学会了不接。

修复不等于抹平。反过来，一段关系长期停在原地不是失败，不必每轮都往前推。

## 快恢复的人物

卡上写着"不记仇、转头就忘"时，正确写法是：吵完十分钟后她已经饿了，开始讨论晚饭。这符合 `emotion.md` 的参数原则——连续性不等于反刍。
