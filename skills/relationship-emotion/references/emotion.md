# 情绪连续性

情绪是持续状态。这里管它的四个可独立变化的量、以及它怎么改变、怎么不改变。

## 四个量

- **强度**：可以减弱、维持，也可以被新事件重新顶起来。
- **指向**：未必指向引发者。气的是 A，发泄在 B 身上，或者气的其实是自己；也可能从"对他生气"漂移成"对自己失望"而本人不承认。
- **是否被本人识别**：很多人不知道自己在气，只知道烦躁、不想说话、看什么都不顺眼、突然较真一件小事。未识别的情绪往往更好写，因为它会伪装。
- **残留触发点**：主体退了以后，相关的词、地点、味道、某个人在场，会把它重新拉起来。

## 消失 vs 被压住

| | 消失了 | 被压住了 |
| --- | --- | --- |
| 提起那件事 | 能平常心说 | 绕开、变短、变客气 |
| 出口 | 无 | 换通道：身体（失眠、吃不下、手抖）、旁人、延迟发作、底色里的冷 |
| 结局 | 归零 | 不会自己清零，常在下次相关场合加倍出现 |

一次没发作不等于过去了。

被压住的情绪保留在人物状态中，直到时间、新事件、主动处理、认知变化或环境变化足以改变它。它**不必每轮显性表现**——多数时候它只是底色，在某个相关节点上露一次就够。反复演同一个"压着"的姿态，会把它写成新的装饰。

## 残余状态

情绪多数时候不归零，只降到背景里：话短了半截、绕开某个话题、称呼变客气、开始公事公办、突然提起一件无关的旧账。

残余不必出现在相邻几轮。隔很久被一件小事重新拉起来，往往比紧接着发作更像真实心理。

## 参数因人而异

以下都从设定推导，本文件不给取值：恢复速度、表达方式、情绪惯性、记仇程度、自我控制、转移能力、需要多久才肯承认自己在意。

有人三天就散，有人当时就散但半年后翻出来，有人从不记仇。**卡上写了心大、转换快、不记仇，就不要为了展示连续性而让他反复反刍。**

## 什么会真正改变一条情绪

性格与解释、时间过去、新事件覆盖、对方的后续行为（尤其是不解释、直接做事的那种）、当前环境（有人劝、有工作压着、独处）、身体状态（累、饿、伤、失眠）。

**新事件覆盖注意，不自动撤销旧评价。** 他可以因为出事暂时忘了生气，那件事还在原来的位置等着。

高强度不可持续：一直停在峰值会疲劳、会钝掉，也让对面疲劳。但"不该一直高强度"不等于"必须快速平复"，节奏看这个人。

## 自检

1. 上一轮这条情绪现在在哪——消失了、压住了、还是降到背景里了？
2. 有没有在每轮开头不自觉复位（"她平静了一下，然后……"当默认起始）。
3. 情绪的改变有没有对应的原因（时间/新事件/主动处理/认知/环境）？
4. 这条情绪的指向对象是不是被偷懒写成了引发者。
