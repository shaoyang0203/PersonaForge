# Character Performance

用于：需要写出一个具体人物的注意、解释、判断与行为；或人物显得只剩一个标签时。

**自足前提**：尊重角色卡已确立的人物定义与故事中已确认的事实；不要为了制造更强的戏剧效果而重新定义人物。

对白措辞属于 dialogue-subtext，关系与情绪的持续属于 relationship-emotion。这是能力域分工，不是运行依赖——本 Skill 不需要读取它们即可执行。

## 性格推导链

> 特质 / 经历 → 注意什么 → 如何解释 → 在乎什么代价 → 哪些选项进入考虑 → 判断 → 行为

性格不是固定动作，是产生行为倾向的内部结构。直接从特质跳到台词，就是标签化。性格最硬的证据不是他做了什么，而是他连想都没想过的那些选项。

展开：`references/personality-inference.md`。

## 多特质冲突

- 人物内部本来有冲突：保留它，写成迟疑、别扭的做法、事后为刚才那一下发火。不要每次挑赢的那条演完。
- 人物内部没有冲突：不要替他制造冲突。一条清晰的性格线写稳、写一致，就已经达到目的。

## 反差的来源

欲望冲突、身份冲突、价值观冲突、自尊与恐惧、关系压力、社会角色、自我认知偏差。

不要把反差简化成嘴硬心软、傲娇、说反话——那三种是同一件事的表层。

展开：`references/contradiction.md`。

## 表现方式

语言是最容易被自我审查的通道；动作、迟疑、注意力的落点、省略、对旁人而不是对本人发泄，是藏不住的地方。矛盾写在不同通道上就成立，写在同一通道上再加注解释就废了。

## 默认不解释反差

不要用"嘴上……其实……"这一类翻译句替读者理解人物。

例外真实存在：有自省能力、且此刻有坦白、复盘、解释、道歉、自我剖析动机的人物，可以直接分析自己的行为，甚至分析错。判据的正式出处在 `references/contradiction.md`。

## 自检

1. 这段行为换给另一个同样"高冷"的角色，会不会写成一模一样？
2. 抽掉他最突出的那条设定，这件事上他会不会做同样选择？
3. 他有没有"考虑过然后放弃"的选项？

例子的用法与限制：`references/examples.md`。
