# 性格推导

`SKILL.md` 的展开。讲性格如何变成行为，不讲角色应该是什么性格。

## 一条特质改变的是四件事

1. **注意什么** —— 他先看到哪个细节，什么对他根本不存在。
2. **怎么解释** —— 同一个中性事件被他读成什么意味。
3. **在乎什么代价** —— 他宁可承受什么，绝不肯承受什么。
4. **哪些选项不进入考虑** —— 最关键的一条。行为层的复读（每次都被动变脸）来自漏掉这一项。

例：高傲不等于说话冲。他的内核是"求助被解释为暴露弱点"，于是"开口求人"默认不在选项集里。由此可以推出很多互不重复的表现：先选一条成本更高的路自己解决；把递过来的帮助听成怜悯；在没人看见时做同一件做不到的事，只做一半；用给别人的帮助换取自己接受帮助的机会。

推导链走完后，同一句设定可以产生一整套不重复的行为，也能产生一句很平的台词（如果他今天根本没遇上那件事）。

## 不同关系里的不同表现

每个人对不同人有一套不同的成本表。对上级谨慎，对同辈逞强，对唯一知道自己底细的人反而最容易失控——因为只在他面前伪装成本最高。

写法：不写"他对别人冷、对他热"的切换，写同一句话由不同人说出时，他给出完全不同的解读。

## 压力与环境

公开场合、独处、身体虚弱、极度疲劳、压力峰值，削弱的是自我控制的余量，暴露的是本来就压在那里的部分。失态不是新增人格，是同一个人被拿掉了修饰。

"压力越大越客气"和"压力越大越刻薄"都成立，取决于他的自尊挂在什么地方。

## 长期改变与回潮

改变走积累路径：经历 → 反复得到验证 → 变成预期 → 变成默认反应。允许的方向是习惯松动、防卫点转移、旧目标让位、对自己某部分的容忍度变化。

不允许的方向是因剧情需要一夜变一种人。

真实的改变带回潮：改好的毛病在疲劳、被戳到、回到旧环境时再出现一次。回潮不是写崩，是改变真的发生过的证据。

## 自检

- 这条性格在这段戏里有没有产生"注意 / 解释 / 代价"三层中的任何一层变化？只有台词层的重复，就是标签化。
- 他这一轮有没有一个被排除掉的选项？只写已经想到的动作，人物是平的。
- 卡上写了多条性格，参与决策的有几条？只用一条时，其余几条从未生效——回去补推导，不是补台词。
