# 剧情从哪里长出来

## 目标不相容的四种摩擦

不需要新事件，只要把已有目标放到一起：

- **直接冲突**：两个人要同一个东西，或一个要另一个不做某事。
- **资源冲突**：目标不矛盾，但时间、钱、人手、信息不够。
- **手段冲突**：都想要同一结果，但对"可以付什么代价"看法不同（这类最适合长场景）。
- **层级冲突**：短期目标与长期目标打架，或私人目标与职责打架。

写推进时先查这一章的四类，再考虑加新事件。

## 选择与后果

摩擦要变成剧情，通常要有人做一个选择。要点：

- 选择要有放弃的那一项（没有代价的选择只是排列，不是决定）。
- 谁做这个选择，决定后续谁在意这件事。
- 后果要分层：立刻可见的（局面变了）、延迟的（几天后才显形）、只影响关系的（态度变了）。

## 新局面如何产生新目标

后果改变的是人物手里的条件，于是目标自然更新：原来的办法不再可行、出现了新欠债、有人知道了原本不知道的事、某条路被封。

推进不是"接下来发生什么"，而是"现在谁最想要什么、谁最怕什么"。这两个问题答出来，下一步通常不需要发明。

## 什么叫廉价推进

| 表现 | 为什么廉价 |
| --- | --- |
| 突然袭击、车祸、失忆 | 没有前提，与人物目标无关，换成任何一个场景都能插进去 |
| 不断冒出神秘人物 | 用未知代替因果 |
| 当场揭晓重大秘密 | 该秘密在此之前没有产生任何作用 |
| 事件演完不留痕迹 | 没有后果，等于没发生 |
| 强度递增但内容重复 | 只是把同一拍拧大 |

反面标准：一个推进要成立，删掉它之后局面应该会不一样。删了没差别的事件是装饰。

## 谁推动

事件由人物推动时才算剧情。旁白宣布变化（"三天后，事情传开了"）可以用，但要接一个可见后果，且不要用它代替人物的选择。
