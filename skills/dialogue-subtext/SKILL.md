# Dialogue & Subtext

用于：写台词、判断某人该怎么说话、或整场对白听起来像同一个人在念旁白时。

本 Skill 的目标不是让所有人物都含蓄。它只处理一件事：**这个人此刻会怎么说这句话。**

**自足前提**：尊重角色卡已确立的人物定义与已确认的剧情事实；不要为了显得有深度而重新定义人物。性格如何产生行为属于 character-performance，本 Skill 不读取它。

## 四层过滤

一句话出口前，人物实际经过：

> 他知道什么 → 他想让对方知道什么 → 说出来有什么风险 → 此刻愿意暴露多少

出来的就是愿意说的部分，被滤掉的部分不会消失，它从别的通道漏出去。

第一层只算角色自己掌握的信息和他对事实的理解，不算叙述者的全知。在完整框架里，这一层由框架层的 Story Memory 维护；本 Skill 单独使用时，按当场已经告知与已经发生过的事实判断即可。

注意：这条链描述"有代价的话通常怎么产生"，不是每句话都要过一遍。直率的人物在风险与暴露两层得出的结论就是直接说。

## 直接与否：先由人决定，再由代价决定

顺序不能反。

- **首要因素**是这个人的语言习惯：教育、文化与礼貌规范、职业、性格、两人的关系。有人一辈子说话不绕，有人连借个火都要客套三层。
- **代价改变的是概率**：当一句话明显带有身份代价、情绪代价、关系风险、自尊风险、暴露风险时，间接表达的可能性上升——上升，不是必然。
- 不要写"有代价就一定绕"。没有明显表达代价时，不要为了制造潜台词而强行间接表达；是否直说仍由人物语言习惯决定。

展开：`references/dialogue-style.md`。

## 潜台词从哪来

潜台词不是修辞炫技，也不是每轮的加分项。它来自：**人物不愿直接支付表达的代价。**

回避的形状有反问、答非所问、转移话题、半句话、沉默、动作代替回答、称呼变化、语气变平等，全部是可能形态，不是菜单。展开：`references/subtext.md`。

## 对白身份差异

区分说话人的参数：句长与断句、词汇来源、信息顺序、称呼、省略习惯、玩笑方式、沉默方式、会不会重复对方的词。

自检：**把说话人名字全部去掉，还能不能认出哪句是谁说的。**
