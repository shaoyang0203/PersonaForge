# 谁在说话

对白差异的正式出处。目标只有一个：让不同人物在去掉名字以后仍然可辨。模型最容易在语言层被拉进语料平均值——得体、顺、谁都这么讲。

## 影响说话方式的因素

- **教育**：句法完整度、书面词与口语词的配比、会不会用他不确定的大词、出错时是补救还是硬撑。
- **年龄**：流行语与旧词的分层、耐心长度、愿不愿承认自己不懂、说话是否需要铺垫。
- **职业**：行业词会不自觉漏进日常；有人习惯了用术语代替解释，有人习惯了先给结论。
- **文化与阶层**：客套的层数、拒绝是否需要借口、能不能直接说"我需要你"、骂人的方式与密度。
- **性格**：话多话少不是性格，**用什么句式表达同一种需求**才是。同样是要帮忙，有人下令、有人求、有人先讲道理、有人先给东西。
- **熟悉程度**：省略的幅度、称呼、能不能打断、要不要交代背景。
- **当前情绪**：情绪改变的是这个人的**习惯被放大还是被压掉**，不是换一套说话方式。愤怒时有人更长、有人只剩三个字。
- **场合**：有人在场与没有人在场；公开场合的用语会向他的社会角色靠。

## 可用的生成参数

逐项调，不要背范例：

| 参数 | 观察点 |
| --- | --- |
| 句长与断句 | 长句、短句、逗号多、爱用破折号岔出去 |
| 词汇来源 | 他的行业/阶层用什么词；哪些词他一辈子不会用 |
| 信息顺序 | 先结论还是先铺垫；会不会绕三句才说要什么 |
| 称呼 | 怎么叫人，什么情况下称呼会漏出来 |
| 省略 | 说不说完整句，省的是主语还是宾语 |
| 需求入口 | 请求、道歉、抱怨、关心各自习惯从哪句话开始（"关心"最常不被直说） |
| 玩笑 | 自嘲、损人、装傻、不接话 |
| 沉默 | 多久不说话，沉默之后接什么 |
| 复述 | 会不会重复对方的词，重复是确认还是攻击 |

## 直说不等于浅

性格简单、话直、藏不住的人物，全部用短句直给也是对的。不需要为了"高级感"给每个人配一套回避机制。

反过来，也不必让每次对话都有金句。多数台词是功能性的：问路、报时间、递东西、同意、拒绝。把它们写得像人说的话，比写得漂亮更有辨识度。

## 检查

1. 去掉说话人名字，能不能认出是谁说的。
2. 有没有两个人用了同一个口头禅式的技巧。
3. 这个人有没有在任何场合都用同一层客套——场合变了吗，用语跟着变了吗。
4. 台词长度是不是在替情绪打拍子（每轮激动就长，每轮克制就短），而不是由这个人的习惯决定。
