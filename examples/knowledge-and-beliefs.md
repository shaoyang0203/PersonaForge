# 示例：知识边界与错误理解

对应 [runtime/story-memory.md](../runtime/story-memory.md) 的三层分离。这是本项目最核心的一类失效来源：模型知道一切，于是角色也跟着知道一切。

> 场景与句子只为说明结构，不是可复用模板。人物为原创、普通、非成人、非冲突向的日常设定。

## 1. 客观事实

```text
WORLD FACTS / IMPORTANT EVENTS
- C（隔壁街的文具店老板）私下找 B，问她愿不愿意周末去市集帮她记账，一天一结。
- B 当场回绝了，理由是周末要照顾家里。
- B 没有主动告诉 A，只在收工时对 A 提了一句："有人找我做点事，我——"，话被进货单打断。
```

真相在这里：**B 没有背叛任何人，她连那个活儿都没接。**

## 2. A 知道什么

```text
KNOWLEDGE BOUNDARIES
- "有人找 B 做事"：A 知道（听见前半句）；B 知道（她自己拒绝的）；C 知道。
- "B 拒绝了"：A 不知道；C 知道；B 知道。
- "A 起疑了"：B 不知道；A 自己知道。
```

A 只拿到半句话，还是被打断的前半句。这是场面的真实条件，不是需要被修补的信息漏洞。

## 3. A 如何理解

```text
BELIEFS / INTERPRETATIONS
- A 关于"B 与 C 私下接触"：她在被挖，或者已经在替那边做事。
  | 客观事实是否支持：不支持
  | 形成于：那半句被打断的话 + 上周 C 问过她进货渠道
  | 动摇它需要什么：亲耳听到 B 回绝，或看到 C 的原话
```

第三层是错的。它仍然要保留，并且继续起作用。

## 4. 按错误理解来演

A 的店规、性格（不肯正面问人、习惯用安排代替谈话）决定她不会开口核实，而是改条件：

> 她把供应商的报价单从共享抽屉挪到自己包里。周三她让 B 专心守店，自己跑去给老客户送样，那笔单子后来落到另一个店员手上。
> 第四天，收银台边贴出一张"招兼职"的手写纸。

B 的反应是真实的困惑——她不知道发生了什么，也没做错什么。这个错位本身就是剧情资源，比"两人当场把话说清楚"要有戏得多。

**关键约束**：模型在第 1 节就知道 B 是清白的。写 A 的时候，只能用第 2 节的知识和第 3 节的理解。如果 A 表现出任何"她知道 B 其实拒绝了但仍在试探"，就是越界（[Quality Check](../references/quality-check.md) 第 10 项）。

## 5. Active State（这一场需要什么）

进这一场不需要整份记忆，只取相关的：

```text
ACTIVE STATE
SCENE — 店里，周四傍晚，只有 A 和 B
ACTIVE KNOWLEDGE — B 不知道 A 在疑心；A 不知道 B 已经回绝
ACTIVE BELIEFS — A：B 可能被 C 那边挖走（不支持事实）
OPEN NOW — 那句被进货单打断的话
```

`OPEN NOW` 那一行是这场戏能不能自然收口的地方：它给了"新证据"一个已经在场的入口，不需要临时造事件。

## 6. 新证据改变理解

```text
事实层变化：
- B 在店里接 C 的电话，明确说："不去，我周末走不开。我跟我们老板说好了的。"
- A 在柜台后面听见了后半句。

状态更新：
BELIEFS
- A 关于"B 与 C"：原来是她在被挖 → 现在：她回绝了，那半句是别的意思。
  | 动摇它需要什么：已发生（她自己听见）
  | 残余：她自己也没弄明白那句"我——"到底想说什么。
```

## 7. 改变不等于立刻复原

信念被推翻之后，A 不能像程序改了参数一样立刻回到原状。合理的余留是：

- 招聘那张纸第二天被收起来，但**没人提起它**；
- 她开始过度补偿——把原本不打算给 B 的单据让她一起看；
- 她仍然不知道那句被切断的话是什么，这个空白会继续存在（新的 OPEN LOOP）。

而 B 这边也有余留：她注意到那张招聘纸，也注意到自己突然被多分了权限。她同样不知道原因。**两个人各自持有半个解释**，这才是误解被解开之后的真实形状——不是双方同步恢复默认。

## 8. 一句话总结

> 模型知道真相，不代表角色拥有正确理解；误解被澄清，也不代表两个人回到原点。
