# 示例：最基础的人物推导

对应 [skills/character-performance/SKILL.md](../skills/character-performance/SKILL.md)。

> 本文的角色、事件与句子都是为说明结构而写的，不是可复用模板。要带走的是推导方法，不是这些具体表达。

## 1. 角色设定

```text
林安，31 岁，社区图书馆管理员。
守时；怕麻烦别人；对数字和日期过目不忘；
和妹妹长期不说话，原因这里不需要交代。
```

三条有效信息：**守时**、**不开口求人**、**记得住细节**。

## 2. 当前事件

周六上午，同事发来消息：自己有事，请林安替一天的班。林安那天下午约了去医院复诊，挂号排了两个月。

## 3. 不推导时容易出现的平面表现

> 林安皱了皱眉。她是个善良的人，总是先替别人着想。她叹了口气，回复："好吧，我来。"她心里虽然有些无奈，但想到能帮到同事，还是觉得自己做得对。

问题不在文字，在推导：**"她是个善良的人"被当成了原因**，于是行为直接由这句标签生成，还配了一段替读者解释心理的收尾。换成任何一个"善良"的角色，这段可以原样搬走。

## 4. 走推导链之后

特质 → 注意什么 → 怎么解释 → 在乎什么代价 → 哪些选项不进入考虑 → 判断 → 行为：

- 她先看到的是**时间**：三点挂号，来回路上两小时四十分钟。这个数字她不用查。
- 她把这条消息解释成一次请求，而不是善意——请求意味着她要给出回应，回应意味着开口说明自己也有安排。
- 她绝不肯承受的代价是**欠人一个人情、并且当场说出自己的私事**；她可以承受的代价是自己的时间。
- "我那天也有事，你去问问别人"这一项根本没进她的考虑：那需要开口麻烦别人。

> 林安回了两个字：「几点。」
> 放下手机，她打开日历，把复诊那一栏的时间往后挪了三格，又删掉，重新挪了两格。挂号处改约要工作日打电话，她记着这条规则，也记着自己上一个工作日请过的假。
> 中午她跟同事说：「我下午有点事，四点以后可以。」——她没说要做什么。

同一条设定，行为完全不同：如果她"守时"这条压过"不开口求人"，她可能直接拒绝并说明理由；如果卡上给她的是"怕被人知道自己在意妹妹以外的人"，她可能答应之后一整天都在生闷气。四个方向都合法。

## 5. 差异来自哪里

| 平面写法 | 推导写法 |
| --- | --- |
| 从标签直接跳到动作和台词 | 从标签跳到注意、解释、代价、可选行动，再落到动作 |
| 读者被告知名为"善良" | 读者从改日历、只回两个字、不说私事里自己看出他是什么样的人 |
| 情绪被叙述者解释掉（"心里虽然有些无奈"） | 没有解释，只留下后果：她把复诊时间挪了两次 |
| 换角色可以照搬 | 换一个人，同一事件会产生不同选择 |

一条性格最硬的证据，是这个人在这个处境里**没有考虑过的那件事**——林安从头到尾没想过开口请同事另找人。

自检三问（同 `SKILL.md`）：另一个同样"善良/内向"的角色会不会写成一模一样？抽掉"怕麻烦别人"这条，他还会这样选吗？有没有"考虑过然后放弃"的选项？
