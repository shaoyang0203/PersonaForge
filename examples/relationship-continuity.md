# 示例：关系与情绪的连续性

对应 [skills/relationship-emotion/SKILL.md](../skills/relationship-emotion/SKILL.md) 与 [runtime/story-memory.md](../runtime/story-memory.md)。

> 场景与句子只为说明结构，不是可复用模板。

人称约定：**甲 = 他**，**乙 = 她**。

## 场景

两人合租。上一场：他在客厅把她母亲那句评价当面转述给她——"我妈说你这半年什么正事都没干"。她当场没有发作，只说"我知道了"，回房到凌晨。

下一场：第二天早上，两人在厨房碰面。

## 容易出现的写法：情绪按轮清零

> 早上的阳光很好。她正在烤面包，看到他进来，笑了笑："周末你也不起床？"两人像往常一样斗了两句嘴，昨晚的事谁也没再提。

"谁也没再提"看起来像成熟，实际上是把情绪当成了一段回复的装饰——写完就摘掉。这属于 [Quality Check](../references/quality-check.md) 第 7 项。

## 走连续性之后先摆状态

```text
客观发生了什么：她母亲那句评价被他当面转述出来。
她的理解：他觉得这事无所谓，所以才可以说出来。
情绪：怒意已过大半；剩下的是"被评价"这件事本身。
指向：不是对他，是对她母亲那句话。
是否被识别：没有。她今天只是不太想说话。
```

> 她把面包递过去一片："我妈昨天打电话来了。"话出口才意识到在厨房提这个不合适，顿了一下改口，"——她血压又高了。"
> 她给他倒了水，多问了一句今天几点回。

三处要点：

- 强度已经明显下降，两人能正常说话。**情绪连续不等于还在生气。**
- 有个话题被绕开：整个上午她没有再提"工作"和"半年"这两个词。**这是残余，不是发作。**
- 她的在意换了出口：多倒的一杯水、多问的一句行程、那次改口。**被压住不等于消失，它换通道。**

## 关系记录怎么写

Story Memory 里只动事实层，一行为限：

```text
RELATIONSHIP STATE
乙→甲：尊重 - ；亲密不变；依赖不变
  unresolved: 他曾把她母亲对她的评价当面转述出来（她未表示原谅，也未再提）

CHARACTER STATE
乙
  mood: 已平 | 指向：她母亲那句话，不是甲 | 被压住
```

不要写成"她心里有些不舒服，但对他也生不起气来"——那是描写层，写进去就会退化成聊天摘要。

## 关于恢复速度

如果乙的卡上写着"不记仇、转头就忘"，那么第二天她像什么都没发生就是正确答案，包括正常谈工作。**连续性不等于反刍**：这一条管的是"不许无来源清零"，不是"所有人必须带着情绪残留演很多轮"。

反过来，如果这一场本来就没有待处理的后果——吵完当天就摊开讲清楚了——那么正常说话也不是错误。规则约束的是没有原因的变化，不规定每场必须留一道痕。

## 变体：真正改底座的是小互动

同一套框架里，改动关系底座的往往不是这次争吵，而是连续几周里她每次都被拿"这半年"来打趣、每次结账时都被说一句"你那个工资"。这类累积不会单独进 IMPORTANT EVENTS；它通常等到某句无关的话才被显形——她因为"晚上吃什么"发了大火，那才是前面积下来的东西。
